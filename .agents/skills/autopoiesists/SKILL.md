# The Autopoiesists: 9 Sovereign Perspectives (v1.0)

Orchestrates the 9 Autopoiesist specialists concurrently in a single invoke_subagent call:
1. autopoiesist-founder: Problem-solution fit & value maximization.
2. autopoiesist-cpo: UX, workflows, and ergonomics (3s HUD).
3. autopoiesist-architect: Invariants, YAGNI, AST docking, and decoupling.
4. autopoiesist-dx-lead: 3 AM on-call diagnostics, local test loops.
5. autopoiesist-red-team: Concurrency races, Windows locks, failure vectors.
6. autopoiesist-complex-ai: Non-human emergent mechanics, AST genetic recombination.
7. autopoiesist-sre: Fail-open isolation, timeout budgets, resource determinism.
8. autopoiesist-contrarian: Radical simplification, challenging assumptions.
9. autopoiesist-token-economist: Context window ROI, compute efficiency.
